Automation & Auto-Allow

Automatically approve supported permission and action prompts. These controls only affect prompts Muse can detect on the current page. They do not grant new account or provider permissions.

Enable Auto-Approval Turns automatic approval prompts on or off. Off means Muse will not click approval buttons.
Allow All Actions Approve every detected action on an allowed site, ignoring the individual action filters.
On-Screen Controls Show the Auto-Approval badge and quick controls on supported pages.
Global Action Permissions
App / Connector ActionsConnection, authorization, integration, and plugin approval prompts.
File and Data AccessPrompts to access, upload, download, read, or write files and documents.
External NavigationPrompts to open links, URLs, websites, tabs, or windows outside the chat.
Code ExecutionPrompts to run code, scripts, shell commands, or terminal actions.
Microphone and MediaMicrophone, camera, audio, and other media permission prompts.
Per-Website Rules
A website rule overrides the global action setting for that website. “Always allow” enables automatic approvals there; individual action switches narrow what can be approved.

Network & Proxy Settings

选择网络代理策略。默认开启自适应模式，自动兼容 TUN 虚拟网卡与系统代理，多设备免配置直接联网。

连接模式 (Connection Mode)
推荐 · 默认开箱即用
自动继承 Windows 系统网络代理、VPN 与 Clash Verge 的 TUN 虚拟网卡模式。部署到新电脑无需任何手动设置，免配置畅通联网。
强制所有账号流量经过指定的本地或局域网代理端口（如 Clash HTTP/SOCKS 7897 端口）。
代理协议 (Type)HTTP / SOCKS5
代理服务器 (Host)默认本地 127.0.0.1
代理端口 (Port)例如 Clash Verge 默认 7897
一键填入 Clash Verge 默认 (127.0.0.1:7897)
不经过任何本地或系统代理，直连互联网。
