# 目标

1. 为 Muse 桌面端（Windows, Linux, macOS）提供本地密码锁屏与防窥保护机制，确保用户会话与隐私数据在离开电脑时不被窥视或未经授权操作。
2. 支持三种锁屏触发方式：托盘/界面手动锁屏、全局快捷键锁屏（默认 `CommandOrControl+Shift+L`）、无操作空闲定时自动锁屏。
3. 采用工业级加盐慢哈希（`crypto.scrypt` + 16 字节随机 Salt + 64 字节密钥）存储密码凭证，配合防暴力破解速率限制（失败退避锁定），杜绝彩虹表与硬件穷举破解。
4. 在设置面板（`hotkeys.html`）提供“🔐 安全与锁屏”设置卡片，支持启用开关、设置/修改密码、自动锁屏时间选择与立即锁定。

# 范围

1. **安全加密与存储模型 (`main.js`)**：
   - 使用 Node.js 原生 `crypto.scryptSync` 进行加盐慢哈希计算；
   - 密码哈希、Salt 及锁屏配置收口至 `state.lock` 并持久化存储至 `app-state.json`（支持原子读写与双备份恢复）；
   - 提供时序安全比较（`crypto.timingSafeEqual`），防止时序侧信道攻击；
   - 记录连续失败计数与冷却时间戳，连续输错 5 次后强制锁定 30 秒递增。

2. **锁屏状态与窗口调度 (`main.js` & `lock.html`)**：
   - 维护 `isScreenLocked` 核心状态；
   - 锁定触发时：隐匿所有存活的 `profileWindows`、`mainWindow` 与 `quickWindow`，弹出沉浸式质感 `lockWindow`；
   - 锁定期间：托盘菜单切换账号/快速对话等通道禁用，全局快捷键严格拦截，严防任何绕过锁屏查看会话；
   - 解锁成功时：平滑销毁 `lockWindow`，安全恢复并聚焦当前活动的会话窗口。

3. **空闲检测与定时锁屏 (`main.js`)**：
   - 结合 Electron `powerMonitor.getSystemIdleTime()` 与应用内用户活动时间戳；
   - 启用定时锁屏时，后台轮询检测空闲超时并自动执行静默锁屏。

4. **快捷键与托盘联动 (`main.js`)**：
   - 注册全局锁屏快捷键 `CommandOrControl+Shift+L`，纳入 `DEFAULT_HOTKEYS`，可在快捷键设置中自定义；
   - 托盘右键菜单增加“🔒 锁定客户端 (Lock Screen)”快捷入口。

5. **设置面板与 IPC 桥接 (`hotkeys.html` & `preload-settings.js`)**：
   - `hotkeys.html` 新增“安全与锁屏”选项卡与设置卡片，中英双语国际化支持；
   - `preload-settings.js` 暴露安全受控的 `lockAPI`；
   - `main.js` 接入全套 `lock:*` IPC 处理函数，全部经过 `isTrustedIpcSender` 校验。

# 非目标

1. 不接入操作系统系统级生物识别（Windows Hello / Touch ID / PAM 指纹认证），保持纯本地通用密码机制。
2. 不进行服务端云端密码同步或网络远程鉴权，密码完全受控于本地设备。
3. 不破坏现有的多 Partition 会话隔离与窗口常驻架构。

# 验收示例

- **AC-1 (密码设置与高强度加密)**：首次启用锁屏密码需确认输入两次一致密码，经 `scrypt` 加盐哈希后安全写入 `app-state.json`，文件中绝无明文或弱 MD5/SHA 密码。
- **AC-2 (密码修改校验)**：已设置密码时，修改密码必须提供旧密码并校验通过，旧密码错误时拒绝更新。
- **AC-3 (手动与快捷键即刻锁屏)**：按下 `Ctrl+Shift+L` 或在托盘菜单点击“锁定客户端”或设置页点击“立即锁屏”，所有会话窗口立刻隐匿并弹出锁屏窗口。
- **AC-4 (定时空闲自动锁屏)**：开启定时锁屏并配置时长（例如 1 分钟/5 分钟），系统无操作达到设定时长后自动触发锁屏。
- **AC-5 (锁定态越权拦截)**：锁屏状态下，按快捷键切换账号（Ctrl+Shift+N）、打开设置或快速对话均被拦截，托盘仅允许解锁或退出，无法窥视任何会话。
- **AC-6 (解锁恢复与防暴力破解)**：输入正确密码后立即关闭锁屏窗并恢复原有账号会话；连续输错 5 次后提示冷却倒计时并暂时禁用解锁，阻断暴力破解。
