# 目标

为 Muse Windows 桌面端实现完整的多账号体系与贴边快捷切换交互，满足用户及家庭成员在同一设备上登录、独立使用与快速切换的需求：
1. **多账号独立会话隔离**：至少支持管理 7~8 个以上的独立账号，每个账号基于独立 Session Partition (`persist:muse-${profileId}`) 隔离登录凭证（Cookie/LocalStorage）。
2. **直观的贴边 Dock 栏 UI**：在界面左侧/左下角提供深色磨砂质感的账号切换悬浮/贴边 Dock 栏，清晰展示所有账号的圆形徽章与活跃状态，支持一键点击秒切。
3. **完整的账号生命周期管理**：支持快速新建账号（「+」）、为每个账号自定义备注名称（如“主账号”、“家人A”）、单个账号独立登出（清空当前账号登录态而不影响其他账号）及删除账号。
4. **快捷键与系统托盘联动**：支持全局快捷键（如 Ctrl+Shift+N）快速轮巡切换账号，并在系统托盘菜单与主界面实时同步账号状态。
5. **目标 Spec**：引入 `specs/multi-account/spec.md` 规范账号会话管理能力。

# 范围

1. **核心数据结构与主进程逻辑 (`main.js`)**：
   - 扩展 `state.profiles` 支持备注名 `name`、唯一标识 `id` 与头像标识，提供添加、重命名、删除、独立登出与切换 IPC 处理器。
   - 提供安全的 IPC 通信通道 (`account:list`, `account:switch`, `account:add`, `account:rename`, `account:signout`, `account:delete`)。
   - 保持系统托盘（Tray Menu）与界面 Dock 状态实时双向同步。
   - 增强全局快捷键轮巡逻辑，支持轮巡已配置的所有 Muse 账号并给出桌面通知。
2. **渲染层预加载与 Dock UI (`preload-chat-export.js`)**：
   - 注入现代深色磨砂玻璃（Dark Glassmorphism）质感的左侧/左下角多账号 Dock 栏 `#muse-account-dock`。
   - 展示所有账号圆形徽标，当前活跃账号具备发光光环（Active Ring）与状态标识。
   - 悬停浮层 Tooltip 显示账号完整备注名。
   - 底部提供「+ 添加账号」按钮及右键/更多操作管理菜单（重命名、独立登出、删除账号）。
   - 支持收起/展开折叠按钮，避免遮挡 Muse 网页既有侧边栏功能。
3. **多账号存储隔离 (`session.fromPartition`)**：
   - 严格沿用 `persist:muse-${profileId}` 的隔离分区策略，登出当前账号仅清空当前 Partition 的 Storage 数据，其余账号不受干扰。

# 非目标

1. 不修改 Muse (muse.ai) 远程服务端的任何业务逻辑或登录验证流程（纯客户端多会话宿主能力）。
2. 不将多个不同账号的聊天数据在本地合并或交叉索引。
3. 不限制账号数量上限（可扩展管理超过 10+ 个账号）。

# 验收示例

- [ ] AC-1 (账号容量与展示)：客户端能创建并列出至少 8 个独立账号，主界面左侧/左下角 Dock 栏能正常排布并完整展示各账号徽章与备注。
- [ ] AC-2 (会话隔离)：在账号 A 登录 Muse 后，切换至账号 B 呈现未登录状态，登录账号 B 后切换回账号 A，账号 A 仍保持登录态，互不串号。
- [ ] AC-3 (一键秒切)：点击 Dock 栏任意账号徽章，主窗口平滑切换至目标账号会话并刷新当前页面，当前活跃徽章状态高亮更新。
- [ ] AC-4 (新增账号)：点击 Dock 栏「+」按钮，支持创建新账号并自动切换至该空白会话供新用户登录。
- [ ] AC-5 (账号重命名)：支持对已有账号修改备注昵称（如“工作”、“家人1”），修改后 Dock 栏、Tooltip 及托盘菜单即时同步更新。
- [ ] AC-6 (独立登出与删除)：支持对当前账号执行独立退出登录（仅清除该 Profile 的 Cookie 与本地缓存），支持删除非活跃账号（且至少保留 1 个基础账号）。
- [ ] AC-7 (快捷键轮巡)：使用快捷键（Ctrl+Shift+N）时能够顺次循环切换至下一个账号并触发主窗口更新与提示。
- [ ] AC-8 (Dock 栏折叠与视觉融合)：Dock 栏具备折叠/展开机制，设计风格与 Muse 深色原生界面融为一体，不干扰原有网页元素点击。
