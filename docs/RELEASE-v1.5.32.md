# Muse v1.5.32

这一版的重点是**安全加固**和**多账号出口隔离**，同时修复了链接打开和账号栏的几个问题。

## ⚠️ 升级前请注意

- **以前导出的"含免登录会话"备份是明文**，里面有所有账号的登录信息，请删除这些文件。今后迁移请用新版导出的加密完整备份。
- **默认导出不再包含登录信息和密钥**。需要换电脑时，在 设置 > 备份 里勾选"完整备份"，并设置密码。
- **新增 WebRTC 防护，默认开启**。如果语音或视频通话异常，可以在 设置 > Mihomo > 出口 IP 隔离 里临时关闭。

## ✨ 新功能

**出口 IP 隔离**（设置 > Mihomo > 出口 IP 隔离）
- 一键检测每个账号的真实出口 IP，并标出和别的账号共用出口的账号。
- 实测节点池里每个节点的真实出口，把实际是同一个出口的节点归为一组。
- 一键给每个账号分配一个不和其他账号重复的出口。能不换就不换；改派时优先选同国家或地区的出口。
- 可选定期自动检测：账号共用出口、出口 IP 变化或无法联网时，发系统通知提醒。

**代理**
- 每个账号的出口端口按账号固定，账号重新排序后出口 IP 不会变。
- 新增"严格出口隔离"：账号的专属节点全部失效时直接断网，不借用别的账号的出口。
- Mihomo 内核意外退出后会自动重启并通知你。
- 端口被其他程序占用时，自动换一个空闲端口。

**备份**
- 完整备份用密码加密（scrypt + AES-256-GCM）。

**账号栏**
- 账号间距收紧，同样宽度能多放约 19% 的账号。
- 当前账号更醒目：蓝色光晕、名字加粗、头像下方有蓝色指示条，其他账号调暗。

## 🐛 修复

- 设置页「Meta 账户」点了没反应。现在会用当前账号的登录状态打开。
- 点击聊天里的外部链接后，窗口变成空白。
- 切换账号时，账号栏有时会整体左移，右边空出一块。
- 站内分享和文档链接改为在应用内用当前账号打开，不再跳到没有登录状态的系统浏览器。
- 账号重新排序后，各账号之间可能互换出口 IP。
- 启动时可能误结束你另外运行的 Clash / Mihomo。
- 飞书同步在账号改名、或表格里有重名时匹配出错。
- 重启 Mihomo 内核时，状态可能被误标成"未运行"。

## 🔒 安全

- 修复：飞书表格或导入的备份里的内容可能被当作网页代码，在所有账号的页面里执行。
- 修复：导入被改过的备份，可能运行任意程序或删除应用目录以外的文件。
- 修复：导入备份新增的账号，在重启前没有权限拦截，麦克风、摄像头等请求会被默认放行。
- 第三方授权弹窗不再加载应用的页面脚本。
- 飞书 App Secret 不再出现在命令行参数里，也不再发给页面。
- 订阅下载限制最大 20MB，并禁止从 https 跳转到 http。
- 主进程接口只接受需要的字段，并删除了 4 个没人调用的接口。

## 🧱 内部改进

- `main.js` 拆分出 7 个模块（`src/`），从约 5280 行减到约 4100 行。
- 新增 `npm test`，包含链接规则一致性检查和 Mihomo 引擎测试。

完整的变更说明和回归清单见 `docs/CHANGES-2026-11-22.md`。
