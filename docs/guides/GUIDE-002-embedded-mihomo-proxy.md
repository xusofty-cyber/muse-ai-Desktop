# 操作指南：内置 Mihomo 代理分流与多账号独立出口队列

## 1. 目标与适用范围
本手册指导用户与操作人员如何在 Muse Desktop 中使用内置的 Mihomo (Clash.Meta) 代理引擎，通过填入机场订阅，为不同的 Muse AI / Meta AI 账号分别指定独立的节点出口队列，实现物理级 IP 隔离与防风控关联。

---

## 2. 前置准备

### 2.1 内核文件准备
Muse Desktop 会自动在以下路径查找 Mihomo 核心二进制：
* **内置路径**：应用根目录下的 `bin/mihomo/`：
  - Windows: `bin/mihomo/mihomo-windows-amd64.exe` 或 `bin/mihomo/mihomo.exe`
  - Linux: `bin/mihomo/mihomo`
* **系统路径**：若本地已安装 Clash Verge，系统路径 `/usr/bin/verge-mihomo` 或环境变量 `PATH` 中的 `mihomo` 会被自动识别。

> **提示**：若未检测到内核，设置界面的状态栏会显式提示“内核文件未找到”，放置二进制后点击重新拉取即可自动就绪。

---

## 3. 操作步骤 (Step-by-Step)

### 步骤 1：开启内置 Mihomo 并配置机场订阅
1. 启动 Muse 客户端，点击托盘图标或使用快捷键打开【偏好设置】页面；
2. 切换至 **【网络与代理】** 标签页，找到 **【内置 Mihomo 智能分流】** 配置卡片；
3. 勾选 **【启用内置 Mihomo 智能代理内核】**；
4. 在 **【机场 Clash 订阅链接】** 输入框中，粘贴您购买的机场提供的 Clash 格式订阅 URL；
5. 点击右侧 **【立即同步节点】** 按钮。
   - 客户端将自动发起请求、追踪重定向并解析出所有海外节点；
   - 状态栏将展示解析成功的节点数量（例如：`✅ 订阅同步成功，已解析 42 个节点`）。

```text
[内置 Mihomo 智能分流]
订阅地址：https://your-airport.com/api/v1/client/subscribe?token=...
[立即同步节点]  [⚡ 全节点延迟测速]
节点状态：已解析 42 个可用代理节点 | 控制器：127.0.0.1:19090 (在线)
```

### 步骤 2：全节点批量延迟测速（可选）
1. 在订阅卡片中点击 **【⚡ 全节点延迟测速】**；
2. 系统将通过内部 REST API 异步对全部节点进行 `generate_204` 延迟探测；
3. 节点标签上将实时渲染各节点的延迟毫秒数与健康色标：
   - 🟢 **绿色**（< 300ms）：高速推荐节点
   - 🟡 **黄色**（300ms ~ 800ms）：普通可用节点
   - 🔴 **红色**（> 800ms 或超时）：不建议作为主用节点

### 步骤 3：为账号分配专属代理队列
1. 点击左侧工具栏的 **宫格图标 (⊞)** 或按下快捷键 `Ctrl+Shift+G`，打开 **账号看板 (Account Hub)**；
2. 找到需要独立 IP 出口的账号卡片（例如“云澈”），点击卡片右上角的 **【编辑】** 按钮；
3. 在弹出的账号编辑弹窗中，找到 **【🛡️ 专属代理出口队列 (Mihomo)】** 配置区：
   - **添加主用节点**：在节点下拉框中选择一个低延迟节点（如“日本-OS-1”），点击“添加至队列”；
   - **添加备用故障转移节点**：可继续添加 1~2 个其他地区的节点（如“美国-US-3”）；
   - **调整优先级**：列表中靠前的节点为主用节点，排在后面的为备用节点；
4. 点击 **【保存修改】**。
5. 此时看板卡片上将显示该账号专属的出口标识：`🛡️ 日本-OS-1 (+1备用)`。

### 步骤 4：无感切换与出口隔离验证
1. 在左侧侧边栏点击切换至该账号；
2. Electron 将自动把该账号的 Session 请求路由到为它单独分配的 Inbound 端口（如 `18002`）；
3. 经由该端口的所有流量将被定向到该账号专属的 Fallback 策略组中，与其他账号完全隔绝。

## 4. 常见问题排查与 FAQ

| 常见现象 / 错误提示 | 产生原因 | 解决处置方案 |
| :--- | :--- | :--- |
| **内核文件未找到** | `bin/mihomo/` 下无对应架构的可执行文件 | 放入对应的 `mihomo` 二进制文件并确保具备执行权限 (`chmod +x`) |
| **订阅拉取失败 (403/超时)** | 机场订阅防刷限制或需要代理访问 | 检查订阅 URL 是否准确，若机场封锁国内直连，可先临时在系统网络配置全局代理后再同步 |
| **端口已被占用 (18000/19090)** | 本地存在其他运行中的 Clash/Mihomo 实例 | 修改其他工具的监听端口，或在任务管理器中关闭冲突的后台进程 |
| **切换账号后网页无法加载** | 账号队列中配置的所有节点均已失效 | 在设置中点击【⚡ 全节点延迟测速】，更换该账号队列中的主备节点 |
| **如何查看底层内核日志？** | 排查复杂网络握手或订阅解析细节 | 日志实时存储于应用数据目录：`<userData>/mihomo/mihomo.log` |
