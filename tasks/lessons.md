# Lessons Learned (项目错题本)

> 本文件记录人类纠偏与架构踩坑经验。Agent 在开始新会话或类似改动前优先阅读，**同一错误绝不犯第二次**。

## 历史经验记录
- [INIT] 项目初始化完成，已接入 Harness 渐进式披露规约与技能库。
- [2026-11-22] **多账号隔离下，账号相关链接绝不交给系统浏览器**：`shell.openExternal` 没有 partition 登录态，会要求重新登录或显示成别的账号。站内/Meta 账户/分享/附件链接必须用发起窗口的 `webContents.session` 在应用内打开，并登记到 `childWindowsByProfile`。
- [2026-11-22] **`setWindowOpenHandler` 里每个 `deny` 分支都必须有可见动作**（跳转、开窗或外部打开），否则用户感知为"点了没反应"。内部路由比较要用完整 URL，不能只比 pathname，也不能忽略 `/`。
- [2026-11-22] **IPC 纳管名单只放自家页面的窗口**：承载第三方页面的子弹窗不加 preload 或用空 preload，也不进 `open-external-url` 等名单；加进去等于给第三方页面开通道。
- [2026-11-22] **导航改道必须区分 will-navigate 与 will-redirect**：服务端 302 链（登录、切号、SSO）中途改道会截断流程，重定向一律保持原行为；改道匹配范围要尽量窄（如只匹配 `accountscenter.*`）。
- [2026-11-22] **main.js 与 preload 的链接规则是两份拷贝**：改任何一边后必须跑 `npm run check:links`。审查结论要先复核代码再下（offlineAPI 实际早已有 `file:` 守卫）。
- [2026-11-22] **备份文件按"可能被篡改、可能被泄露"设计**：导出默认不含凭据，含凭据必须加密；导入逐字段白名单，可执行文件路径、端口一律不随备份迁移。
- [2026-11-22] **会拼进路径或分区名的 id 必须校验字符集**（`SAFE_ID_RE`），递归删除前再确认路径仍在预期目录内。
- [2026-11-22] **资源分配不能依赖列表顺序**：会被重新排序的列表（账号）不能用下标分配端口等资源，要按 id 固定并持久化。
- [2026-11-22] **只杀自己启动的进程**：记录 pid 并核对进程名，绝不按进程名批量 taskkill。
- [2026-11-22] **子进程 exit 回调要确认还是"当前"进程**：restart 时旧进程的 exit 可能晚于新进程启动。
- [2026-11-22] **`state` 不要直接整体赋值**：拆分后状态对象由 `src/state.js` 持有，`state = {...}` 会让内存与落盘脱节；一律 `state = replaceState(next)`。
- [2026-11-22] **外部数据不进 innerHTML**：飞书表格、导入备份、订阅节点都可能被他人控制，preload 运行在每个账号页面里，拼进 HTML 等于让外部内容以站点身份执行。审查时要扫描所有 `innerHTML` / 模板字符串里的 `${}`，而不只看今天改过的代码。
- [2026-11-22] **会话级处理要挂在"使用会话"的入口上**：权限拦截、下载处理不能只在启动和新增账号时设置，任何新出现账号的路径（导入、恢复）都会漏掉。
